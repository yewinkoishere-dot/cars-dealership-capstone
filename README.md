# Cars Dealership - Full-Stack Capstone Project

## Project Name
**Cars Dealership National Application**

## Description
A responsive national car dealership web application built using Django, React, Node.js, Express, MongoDB, and SQLite. The application allows users to view dealership locations across the U.S., read customer reviews, submit reviews, and analyze customer sentiment.

## Architecture & Stack
- **Frontend:** React, HTML5, CSS3, Bootstrap
- **Backend:** Django (Python), Node.js (Microservices)
- **Databases:** MongoDB (Dealers & Reviews), SQLite (Users & Car models)
- **Deployment:** Docker, Kubernetes, IBM Cloud Code Engine
- **CI/CD:** GitHub Actions
